# mvp-prototypes

Interactive prototypes for Synder product initiatives.

Live: <https://andreyivanitskiy-dotcom.github.io/mvp-prototypes/>

## Projects

- [DIS-358 — Yearly history carrot](projects/dis-358-yearly-carrot/mock/) — pricing badge + in-app banner variants promoting free 1yr history for yearly plans.
- [DIS-547 — Shopify: reconcile all clearing accounts of a store](projects/dis-547-shopify-store-recon/) — Run one Shopify store against all its clearing accounts (Shopify Payments, POS, Manual, Other), with per-account results and an Outside clearing accounts breakdown.
